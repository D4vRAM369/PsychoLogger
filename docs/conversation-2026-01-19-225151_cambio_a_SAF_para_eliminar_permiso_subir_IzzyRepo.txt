  Sección 2: Flujo de Autobackup con SAF                                                                                                                    
                                                                                                                                                            
  Primera vez (configuración):                                                                                                                              
  Usuario va a Ajustes → "Configurar carpeta de backups automáticos"                                                                                        
           ↓                                                                                                                                                
      SAF Directory Picker (ACTION_OPEN_DOCUMENT_TREE)                                                                                                      
           ↓                                                                                                                                                
      Usuario selecciona carpeta (Drive, SD, carpeta local...)                                                                                              
           ↓                                                                                                                                                
      App guarda URI con takePersistableUriPermission()                                                                                                     
           ↓                                                                                                                                                
      URI se persiste en SharedPreferences                                                                                                                  
           ↓                                                                                                                                                
      Autobackup habilitado ✓                                                                                                                               
                                                                                                                                                            
  Cada 12 horas (BackupWorker):                                                                                                                             
  WorkManager dispara BackupWorker                                                                                                                          
           ↓                                                                                                                                                
      ¿Hay URI persistido?                                                                                                                                  
           ↓                                                                                                                                                
      NO → Skip (autobackup no configurado)                                                                                                                 
      SÍ → Crear ZIP en cacheDir                                                                                                                            
           ↓                                                                                                                                                
      Abrir OutputStream via ContentResolver usando URI persistido                                                                                          
           ↓                                                                                                                                                
      Copiar ZIP al destino                                                                                                                                 
           ↓                                                                                                                                                
      Eliminar ZIP temporal de cacheDir                                                                                                                     
           ↓                                                                                                                                                
      Rotación: mantener últimos 7 backups en esa carpeta                                                                                                   
                                                                                                                                                            
  Beneficios:                                                                                                                                               
  - Sin permisos de storage requeridos                                                                                                                      
  - Usuario controla exactamente dónde van sus backups                                                                                                      
  - Funciona con Google Drive, OneDrive, SD cards, etc.                                                                                                     
  - El URI persiste aunque se reinicie el teléfono                                                                                                          
                                                                                                                                                            
  UI necesaria en ProfileSettingsScreen:                                                                                                                    
  - Botón "📁 Configurar carpeta de autobackups"                                                                                                            
  - Indicador de estado: "Autobackup: Activo → [carpeta]" o "No configurado"                                                                                
  - Opción para desactivar/cambiar carpeta

  class BackupWorker(context: Context, params: WorkerParameters) : CoroutineWorker(context, params) {                                                       
                                                                                                                                                            
      override suspend fun doWork(): Result {                                                                                                               
          val backupPrefs = BackupPreferences(applicationContext)                                                                                           
                                                                                                                                                            
          // 1. Verificar si autobackup está habilitado                                                                                                     
          if (!backupPrefs.isAutobackupEnabled()) {                                                                                                         
              Log.d(TAG, "Autobackup deshabilitado, saltando...")                                                                                           
              return Result.success()                                                                                                                       
          }                                                                                                                                                 
                                                                                                                                                            
          // 2. Obtener URI persistido                                                                                                                      
          val folderUri = backupPrefs.getAutobackupFolderUri()                                                                                              
          if (folderUri == null) {                                                                                                                          
              showToastIfAppVisible("❌ Autobackup: No hay carpeta configurada")                                                                            
              return Result.failure()                                                                                                                       
          }                                                                                                                                                 
                                                                                                                                                            
          // 3. Verificar que aún tenemos permisos                                                                                                          
          if (!hasUriPermission(folderUri)) {                                                                                                               
              showToastIfAppVisible("❌ Autobackup: Permisos revocados. Reconfigura la carpeta.")                                                           
              backupPrefs.setAutobackupEnabled(false)                                                                                                       
              return Result.failure()                                                                                                                       
          }                                                                                                                                                 
                                                                                                                                                            
          return try {                                                                                                                                      
              showToastIfAppVisible("🔄 Iniciando backup automático...")                                                                                    
                                                                                                                                                            
              // 4. Crear backup en caché                                                                                                                   
              val backupManager = BackupManager(applicationContext)                                                                                         
              val tempFile = backupManager.createBackupInCache(                                                                                             
                  localStorageData = getLocalStorageSnapshot(),                                                                                             
                  password = null,  // Autobackups sin cifrar                                                                                               
                  includeMedia = true                                                                                                                       
              ) ?: throw Exception("No se pudo crear backup")                                                                                               
                                                                                                                                                            
              // 5. Generar nombre con timestamp                                                                                                            
              val timestamp = SimpleDateFormat("yyyy-MM-dd_HH-mm-ss", Locale.getDefault()).format(Date())                                                   
              val fileName = "autobackup_$timestamp.zip"                                                                                                    
                                                                                                                                                            
              showToastIfAppVisible("💾 Guardando backup...")                                                                                               
                                                                                                                                                            
              // 6. Crear archivo en carpeta SAF                                                                                                            
              val folder = DocumentFile.fromTreeUri(applicationContext, folderUri)                                                                          
              val newFile = folder?.createFile("application/zip", fileName)                                                                                 
                  ?: throw Exception("No se pudo crear archivo en destino")                                                                                 
                                                                                                                                                            
              // 7. Copiar contenido                                                                                                                        
              applicationContext.contentResolver.openOutputStream(newFile.uri)?.use { output ->                                                             
                  tempFile.inputStream().use { input ->                                                                                                     
                      input.copyTo(output)                                                                                                                  
                  }                                                                                                                                         
              }                                                                                                                                             
                                                                                                                                                            
              // 8. Limpiar temporal                                                                                                                        
              tempFile.delete()                                                                                                                             
                                                                                                                                                            
              // 9. Rotación (mantener últimos 7)                                                                                                           
              backupManager.cleanOldBackupsInSaf(folderUri, keepCount = 7)                                                                                  
                                                                                                                                                            
              // 10. Actualizar timestamp                                                                                                                   
              backupPrefs.updateLastAutobackupTime()                                                                                                        
                                                                                                                                                            
              showToastIfAppVisible("✅ Backup automático completado")                                                                                      
              Result.success()                                                                                                                              
                                                                                                                                                            
          } catch (e: Exception) {                                                                                                                          
              Log.e(TAG, "Error en autobackup", e)                                                                                                          
              showToastIfAppVisible("❌ Backup automático falló: ${e.message}")                                                                             
              Result.retry()                                                                                                                                
          }                                                                                                                                                 
      }                                                                                                                                                     
                                                                                                                                                            
      private fun hasUriPermission(uri: Uri): Boolean {                                                                                                     
          return applicationContext.contentResolver.persistedUriPermissions                                                                                 
              .any { it.uri == uri && it.isReadPermission && it.isWritePermission }                                                                         
      }                                                                                                                                                     
                                                                                                                                                            
      private fun showToastIfAppVisible(message: String) {                                                                                                  
          if (isAppInForeground()) {                                                                                                                        
              Handler(Looper.getMainLooper()).post {                                                                                                        
                  Toast.makeText(applicationContext, message, Toast.LENGTH_SHORT).show()                                                                    
              }                                                                                                                                             
          }                                                                                                                                                 
      }                                                                                                                                                     
  }
